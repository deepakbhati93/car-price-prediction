# 🚗 Car Price Prediction

A Machine Learning-based web application that predicts the price of used cars based on various vehicle features. This project helps buyers and sellers estimate a fair market value using historical car data and predictive analytics.

---

## 📌 Project Overview

Car Price Prediction is an intelligent application that estimates the selling price of a used car using machine learning algorithms. The model is trained on historical car data and considers multiple factors such as brand, model, manufacturing year, fuel type, transmission, ownership, and kilometers driven.

The application is built with **Python**, **Scikit-learn**, and **Streamlit**, providing a simple and interactive user interface for instant price prediction.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Car-Price-Prediction.git
```

Move into the project folder

```bash
cd Car-Price-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
